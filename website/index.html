Android Enterprise Security Lab
Educational Security Research Framework

Non-Destructive Android MDM Diagnostics & Analysis

An open-source diagnostic suite to inspect Android DevicePolicyManager (DPM) APIs, hardware root of trust mechanisms, and enterprise management signatures.

Get Started View Source

Key Architectural Pillars

DPM & Policy Inspection

Audit Device Owner (DO) and Profile Owner (PO) privileges, active admin packages, and custom system overlay behaviors safely via ADB.

Hardware Root of Trust

Analyze hardware-backed attestation models, Samsung Knox eFuse mechanisms, and secure enclave integration in enterprise devices.

Automated Setup Wrappers

Cross-platform setup utilities for Linux, macOS, and Windows PowerShell to automate platform-tools configuration without manual setup.

Quickstart Diagnostic Commands

Run the Python inspection engine or Bash diagnostic tool to generate structured audit reports:

# Clone and inspect active MDM packages
$ git clone https://github.com/your-username/android-enterprise-security-lab.git
$ cd android-enterprise-security-lab
$ python3 core/mdm_inspector.py
# Or run rapid bash ADB check
$ chmod +x scripts/adb_check.sh && ./scripts/adb_check.sh
